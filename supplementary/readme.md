# Supplementary Audit Records

This directory contains convenience audit artifacts derived from the primary
machine-readable evidence.

## lopo_foldwise_audit_summary.csv

Six-row fold-wise audit linking each omitted magnetic perturbation to:

- predictive NRMSE and noise-floor-normalised error;
- identified modal quantities and topology;
- complete-FRF plasma-reference complex discrepancies;
- phase and magnitude discrepancies; and
- best-achievable structural damping results.

The file is derived from the primary Case 1F, Case 3C, and Case 3D evidence
and does not introduce additional numerical analysis.
